# Life in Darkness

**501(c)(3) Nonprofit Organization · Canyon Lake, California**

An independent nonprofit building emotional and cognitive capacity upstream of crisis — formation for first responders, youth, families, survivors, and caregivers.

## Deployment

Static HTML site deployed on [Netlify](https://www.netlify.com).

- **Push to `main`** → auto-deploys to production
- **Forms** → Netlify Forms (contact, volunteer, faith-community, newsletter)
- **Redirects** → `netlify.toml` + `_redirects`

## Site Structure

| Route | Page |
|---|---|
| `/` | Home — founding city thesis, three doors, Behind Both Badges™ countdown |
| `/programs` | Who We Build — three formation doors |
| `/about` | Story, leadership, origin |
| `/help` | Formation pathway routing |
| `/donate` | Giving — unrestricted model |
| `/contact` | Contact and inquiry forms |
| `/volunteer` | Serve — volunteer application |
| `/resources` | Resource library |
| `/faith` | Faith community partnerships |
| `/privacy` | Privacy policy |
